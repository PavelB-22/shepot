# Shepot — голос в текст, бесплатно и без интернета

Зажал клавишу → сказал → отпустил → текст появился там, где курсор. В Telegram, браузере, Word, где угодно.
Распознавание работает прямо на компьютере (модель Whisper), голос никуда не отправляется.

## Установка (одной строкой)
**Mac** (Apple Silicon) — открой Терминал и вставь:
```
curl -fsSL https://raw.githubusercontent.com/PavelB-22/shepot/main/install.sh | bash
```
**Windows 10/11** — открой PowerShell и вставь:
```
irm https://raw.githubusercontent.com/PavelB-22/shepot/main/install.ps1 | iex
```
Дальше программа **обновляется сама** (проверяет при запуске и раз в 6 часов). Модель и настройки при обновлении сохраняются.

## Как пользоваться
- При первом запуске выбери качество — модель скачается один раз.
- Зажми **Ctrl+Shift+Пробел** (на Маке **⌘⇧Пробел**), говори, отпусти.
- Режим «Нажал — начал, нажал — закончил» — слова печатаются прямо в поле, пока говоришь.
- Настройки и история — через значок в трее / строке меню.

## Для разработчика
```
npm install
npm run tauri dev      # запуск в режиме разработки
```

## Публикация новой версии (для Павла)
`cd ~/Projects/Shepot && bash publish.sh` — сам поднимет номер версии, отправит на GitHub, сборка ~15 минут. У всех пользователей программа обновится сама.

⚠️ Ключ подписи обновлений лежит в `.secret/updater.key` (в GitHub не отправляется). Его копия должна быть в секрете репозитория `TAURI_SIGNING_PRIVATE_KEY`. Потеряешь ключ — автообновления перестанут работать, храни копию.
